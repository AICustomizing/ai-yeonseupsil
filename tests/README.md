# 의도 기반 테스트

UI(디자인)는 검사하지 않는다. "이 사이트가 하려는 일이 실제로 되는가"만 본다.

```
node tests/intent.test.mjs     # 🔴 있으면 exit 1
```

## 이 테스트가 잡는 것
- 앵커 링크가 실존 대상으로 연결되는가
- 클릭했을 때 실제로 뭔가 일어나는가 (data-* 훅은 처리 JS 존재까지 확인)
- 상대경로 리소스 / og:image 파일이 실제로 있는가
- canonical·og:url 이 실제 배포 도메인과 일치하는가
- 방문자가 신청에 필요한 정보를 얻을 수 있는가 (.tbd, 00명/00,000원)
- 다크모드가 토글+CSS+JS 3박자 갖췄는가, 하위 페이지도 일관된가
- HTML 태그 균형 / 중복 id / 인라인 JS 문법 / JSON-LD 파싱

## 주의
index.html 에는 170KB 임베드 폰트(base64)가 있다. 문자열 검사 시
40자 이상 연속 base64 덩어리를 제거하지 않으면 오탐이 난다.
